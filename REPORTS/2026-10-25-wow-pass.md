### Shared (all 11 pages)
- **Tokens:** steel, cobalt, navy and teal surfaces, ice-blue accent tint, display, heading and statement type scales, machined easing. Radii stay 2px.
- **Self-hosted fonts:** Archivo (wght 500–900, wdth 100–125) and Inter (wght 400–600), subset variable woff2, 72 KB together, OFL licences in site/assets/fonts. Metric-matched fallbacks and font-display: optional give no font swap shift. Google Fonts is gone, so the site makes no third-party requests.
- **Header:** fixed and transparent over the hero. Once you scroll it turns into a blurred glass bar, compresses and draws an accent keyline. Nav links get machined underline wipes.
- **Buttons:** hard-edged, with a light sweep, an arrow rule and a lift on hover. Focus rings are an ice-blue outline with a blue halo, readable on footage, cobalt and black.
- **Footer:** gradient panel with an accent bar, nav in a four-column grid, contact details in columns.
- **Smooth anchor scrolling** via CSS only (no scroll-jacking), and off when motion is reduced.

### Inner pages (scripts/build-pages.py, site/css/pages.css)
- All inner pages are built from the generator. Changes went into the generator and pages.css, then I re-ran it.
- **Page heroes:** Home's type scale and masked word reveal, a per-page tint (cobalt, teal or steel), and a lit ATIS cut-out on the right. The hero image is decorative (alt="") and picked so it doesn't repeat a figure further down the same page.
- **Sections:** numbered 01–n (labels only), tinted in turn, with large headings. Sections with an image alternate sides and put the image on a light stage with parallax and tilt. Sections without an image get a sticky heading column.
- **Tables:** cobalt header row with an accent rule and row hover. Lists have an accent tick. The contact form sits in a framed panel with refined fields.
- **Industries page:** the same four reactive panels sit under the hero and jump to each section.
- I also fixed drift in the generator. It was emitting the CDN GSAP, a missing pages.js, no pre-paint header script and no image dimensions. It now reproduces the shipped pages and inlines the CSS.

Earlier runs on this branch ranged 91–96 on Home and 94–97 on Services. Both pages stay at or above 90 with CLS 0.

The main baseline is slightly flattering. In this sandbox its Google Fonts request fails, so it rendered with no web fonts at all. This branch loads real self-hosted fonts.

How it stays fast:
- The hero still is still the preloaded, srcset-driven LCP image.
- GSAP and ScrollTrigger (115 KB) load only on the first scroll, pointer or key intent, or 8 s after load. Nothing above the fold depends on them, because hero motion is pure CSS.
- The video source attaches after the load event.
- CSS is inlined, which removes four render-blocking requests.
- Cut-outs reserve their height before the image arrives, which fixed a 0.135 CLS I found on Services.
- Off-screen Home sections use content-visibility.
- Bug found and fixed: once the header became fixed, the hero image covered 100% of the viewport, and Chrome stopped counting it as LCP. The animated headline became LCP instead. The picture is now 2px short of full height so the image counts again, with no visible difference.
